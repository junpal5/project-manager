파일 관리

안내

현재 프로젝트를 JSON으로 내려받거나, 기존 JSON 파일로 프로젝트를 불러올 수 있습니다. 프로젝트 버전 스냅샷 저장은 상단의 버전 저장 버튼을 이용하세요.

GitHub 자동 저장 설정

프로젝트를 수정하면 JSON 파일을 GitHub 저장소에 자동 업로드합니다. 토큰은 브라우저 로컬 저장소에만 저장됩니다.

동기화 안내

자동 저장 방식

로컬 저장 후 약간의 지연을 두고 GitHub Contents API로 JSON 파일을 갱신합니다. 저장 배지는 저장 완료 여부를, 동기화 배지는 GitHub 반영 상태를 표시합니다.

권장 경로 예시

research-pm/projects/복지조사/2026_서울시_청년_생활실태조사.json 형태로 자동 생성됩니다.
